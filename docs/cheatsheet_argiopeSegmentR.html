argiopeSegmentR

Máscara del opistosoma de Argiope con una U-Net entrenada, y su paleta dominante en CIELAB. Las etapas de color, artefacto y QA son un port de SegmentR (Boyko 2025); el segmentador es propio.

Instalación

# una vez, desde el comprimido
install.packages("argiopeSegmentR_0.1.0.tar.gz",
                 repos = NULL, type = "source")

library(argiopeSegmentR)
argiope_status()   # ¿lista la máquina?

El modelo corre en Python. Si falta, se construye desde R:

# ~500 MB, torch CPU (suficiente)
argiope_install_python()
# o si ya tienes uno:
argiope_use_python("C:/.../python.exe")

El flujo, en 9 pasos

  1. argiope_status() — comprueba antes de correr
  2. argiope_gallery(dir) — segmenta la carpeta, una sola carga del modelo
  3. argiope_items(g) — la tabla: máscara sí/no, score, tamaño
  4. subset(it, !has_mask) — qué falló y por qué
  5. argiope_palette_of(g, img) — HEX + Lab + cobertura
  6. argiope_plot(g, page) — el grid, página a página
  7. argiope_dashboard(g, img) — la ficha de 4 paneles
  8. argiope_card_grid(g) — fichas por ejemplar, con nombres de color
  9. argiope_pdf(g, file) — todas las páginas a PDF

Uso mínimo

g  <- argiope_gallery("mis_fotos",
                     out    = "runs",
                     run_id = "prueba",
                     n      = 50)   # muestra
g
#> 50 images · 41 with a mask · 9 empty
#> median score 0.958 · pages of 6: 7

it <- argiope_items(g)
argiope_palette_of(g, it$image[1])
argiope_plot(g, page = 1)
argiope_dashboard(g, it$image[1])

Dibujo

argiope_plot
grid paginado; page, per_page, ncol, select, include_empty
argiope_pages
cuántas páginas hay (0 si nada que dibujar)
argiope_dashboard
4 paneles de un ejemplar; file= para PNG. Devuelve las cifras
argiope_pdf
todas las páginas a un PDF
argiope_card
ficha de un ejemplar: recorte + paleta con nombres
argiope_card_grid
una página de fichas; reutiliza argiope_card
argiope_pick
lista de selección múltiple
argiope_pick_one
selección de uno

Seleccionar

# de una lista (interactivo)
sel <- argiope_pick(g)
# por nombre
sel <- it$image[it$has_mask][1:3]
# por posición
sel <- 1:6

argiope_plot(g, select = sel, per_page = 3)
argiope_pdf(g, "sel.pdf", select = sel)

Tres modos de fallo, y cuál se puede filtrar

1 · Sin máscara

Alrededor de una de cada cinco fotos de campo no devuelve nada. Se registra en skipped.csv con su motivo, nunca se descarta en silencio.

Detectable: sí — has_mask == FALSE.

2 · Fragmento

3 de 81 máscaras ocupaban menos del 0,1 % del encuadre: trozos, no abdómenes. Las tres puntuaban por debajo de 0,70 frente a una mediana de 0,959.

Detectable: sí — filtro por score o por área.

3 · Ooteca

El modelo segmenta sacos de huevos como si fueran abdómenes, y lo hace con score 0,98. El score no lo detecta y el área tampoco: son grandes y compactos.

Detectable: no, automáticamente. Hay que mirar.
